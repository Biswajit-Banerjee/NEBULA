# References

Numbers in square brackets throughout this guide, such as [[9]](references#ref-9), point to this list. The numbering follows the NEBULA manuscript.

---

## How to cite

If NEBULA helps your work, please cite the manuscript and, where relevant, the databases it draws on.

> **NEBULA preprint:** Banerjee, B., Smith, D. E., Goldford, J., Williams, L. D. & Petrov, A. S. *NEBULA: A webserver to analyze protein function and domain structure in stoichiometric metabolic contexts.* SSRN preprint 7549379. This preprint has not been peer reviewed. https://ssrn.com/abstract=7549379

- **Web server:** https://apollo2.chemistry.gatech.edu/NEBULA/
- **Source code (MIT licence):** https://github.com/Biswajit-Banerjee/NEBULA
- Please also state the date you used the server, because the underlying data are updated between releases.

**Acknowledgement:** this work was supported by NASA Grant 80NSSC24K0344 to L.D.W., D.E.S. and A.S.P.
